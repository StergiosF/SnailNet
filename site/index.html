The only connections SnailNet makes

  • Update checkTo GitHub when SnailNet starts and every six hours. Nothing installs until you click.
  • Website and game listsFrom GitHub once a day, signed. You can turn it off.
  • Speed testTo Cloudflare, only when you click Measure
  • PingsTo your router and 1.1.1.1 while shaping, to stay just below your internet speed

Questions

Internet broken? The help on GitHub walks you through it.

Read the help for a broken connection

If I close the window, does it stop?

No. A Windows service keeps your rules running. Use Pause to stop.

Will it make my internet slower?

Only a sliver. It stays just under your internet speed, which keeps ping low.

Does it work in every browser?

Yes, any browser. Sites that hide their name count toward the browser's share.

Does it work with my game's anti‑cheat?

Not tested yet. If a game complains, pause SnailNet and open an issue.

Does it shape uploads too?

Yes, once you set an upload speed. Leave it empty to skip uploads.

Does it cost anything?

No. It's free and open source (GPL‑3.0).
